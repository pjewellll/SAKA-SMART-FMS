LOCAL DEMO MODE: No JAR file needed. Run run-demo.bat.

POSTGRESQL MODE ONLY:
1. Download PostgreSQL JDBC driver JAR (pgJDBC) from https://jdbc.postgresql.org/download/
2. Put the downloaded postgresql-42.x.x.jar file in this lib folder.
3. Create the sakasmart database in pgAdmin.
4. Run run-postgres.bat.

The user must not upload or commit database passwords or secret config files.
